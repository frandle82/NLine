# Mitwirken an NLine 💡

Vielen Dank für dein Interesse, zu **NLine** beizutragen! Ob didaktische Anregungen, neue Aufgabentypen oder Code-Verbesserungen – jeder Beitrag hilft, Mathematik für Schülerinnen und Schüler greifbarer zu machen.

## Wie du beitragen kannst

1. **Feedback & Ideen:**
   - Teile Erfahrungen aus dem Unterricht.
   - Schlage neue Zahlstrahl-Szenarien oder Übungsmodi vor.
   - Melde Fehler über [GitHub Issues](https://github.com/frandle82/NLine/issues).

2. **Entwicklung (Pull Requests):**
   - Forke das Repository und erstelle einen neuen Feature-Branch (`git checkout -b feature/mein-feature`).
   - Halte den Code sauber und modular (Vanilla CSS & Vanilla JS).
   - Teste deine Änderungen lokal mit `npm run dev` und `npm run build`.
   - Reiche einen Pull Request mit einer prägnanten Beschreibung ein.
